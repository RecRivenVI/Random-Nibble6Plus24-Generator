# 项目合规说明

本项目使用模板插件提供的合规检查；完整机制见[合规检查机制](../../gradle/conventions/specification/design/mechanism-compliance.md)。

加载器字段清单见[加载器元数据格式](../../gradle/conventions/specification/reference/format-metadata.md)。P-04 检查实际元数据结构，T-02 检查 Target 脚本中重复的版本事实。P-06、P-07 检查派生项目遗留的模板身份与名称，排除模板文件、`NOTICE`、`licenses/` 和验证结果。
