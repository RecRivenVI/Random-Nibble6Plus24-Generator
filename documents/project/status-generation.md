## 生产实现

现有生产路径具备隔离生成、Artifact、物化、POI、光照、SPAWN、FULL 与真实物理邻区交互。隐藏单人存档可以进入、探索、保存退出与重载；`/seed` 显示世界和当前区块种子，Structure Overlay 与 `/locate structure` 仅处理已生成区域。

旧 Ordering 1 世界继续使用九 writer FEATURES；已有 26.3 Ordering 2 试验世界保留其单 writer 切断语义。已保存 FULL 区块不重新生成或覆盖玩家修改。新按需 B 只接入显式标记的 `development_b` 新实验世界，生成后沿用 Artifact、物化、Overlay 与物理生命周期；没有转换旧世界或切换生产默认。

两个独立宿主各 19 项 detached B 对照通过，包含 stored SPAWN palette、全部引用 starts、村庄猫与模板式含硫植被资源访问；三维度生产 FULL、32 次并发去重及修改后重启通过，重载没有 Artifact/SPAWN 再生成。26.3 原版 Jigsaw 读回时会重算包围盒，生成态与原版加载态分别严格对照。B 已采用目标会话内的结构来源复用与经审计的短锁，不复用可变 pieces 或已关闭会话；未审计扩展保持保守路径。

日常 B 交接只携带轻量计数，完整列证明及其密度 hash 留在验证入口；完整目标快照和 Artifact 校验仍保留。同条件四 CPU 前沿的本轮结果见[列证明分离对照](../research/experiment-b_proof_hotpath.md)，结构锁事实见[结构锁调查](../research/investigation-b_structure_locks.md)。局部地形求值仍是主要计算成本，未宣称探索性能已达到原版；不限 CPU 的改进体感由使用者验收。

局部地形查询按读取位置使用原版小批次与角点复用，高度、表面梯度和 material 输入按需建立；密度与含水层/表面缓存上下文分离，未证明的缓存耦合或能力继续精确回退。原始验证见[位置密度查询对照](../research/experiment-b_density_tiles.md)，当前吞吐只以里程碑的冻结版本原版配对为准。仍有必要的整列、稀疏整高度角点、原版含水层边界及完整地形回退，不把它描述成所有邻区计算已消除；旧地图合同不变。

B 已在单目标内复用 stored-biome 输入和只读准备，精确回退不再重复创建已有 palette；原始验证见[回退输入复用对照](../research/experiment-b_fallback_inputs.md)。两个 26.3 Target 的精确部分 BIOMES／TERRAIN、私有装饰副本已完成[冻结内容对照](../research/experiment-native_terrain_freeze.md)，只完成物理依赖实际要求的阶段，未知模组环境保持精确原路径。刷怪笼告警已定位为切断改变地牢箱子候选后，箱子占据中心且被原版保护；不是实体丢失，未改变 B 结果或静默消音。

Repair A/B/C 已处理身份查询的文件系统热路径、SPAWN 重复构建、Lazy Stronghold、POI 主线程归属和正常关闭取消。D1 候选裁剪的历史正确性通过、性能 PARTIAL；这些结果不代表 26.3 已达到原版探索速度。

26.3 BOP/TerraBlender 兼容基线为 PARTIAL：已修复宿主与本地种子共用群系状态，参考路径和轻量路径各九项三维度独立装饰前对照通过，生产 B 的 FULL、修改后保存重启及零再生成通过。完整 B 装饰对照为 16/18；另两个末地比较暴露上游 possible-biome 枚举顺序使原版装饰本身跨 JVM 不稳定，三个独立原生重复已确认。没有忽略方块差异或修改装饰合同，完整兼容门禁仍失败，详见 [BOP 验证](../../validations/compatibility-bop/validation.md)。

## 已知限制

按需 B 的当前主世界完成目标平均需要约三百列局部地形、约八个噪声批次和 biome-only halo；具体范围依 fixture 而变，不能当作固定上限。去掉完整邻区对象不等于去掉所有邻区计算。未证明的表面规则、洞穴表面修复和完整容器/元数据能力使用明确的精确回退。A 的新验证入口复用按需 B，原 A 保留为完整准备的对照，不自动切换生产。

新白桦入口的准备/矿脉/树木完整回退分别为：birch-0 的 0/0/0、birch-1 的 4/2/1、birch-2 的 0/1/0、birch-3 的 1/0/0；两次宿主结果相同。涉及挖到草地/菌丝后的 topMaterial 梯度等未证明读取，不强称所有邻区计算消除。准备和补充查询仍可能重复噪声批次或同种子完整回退，尚未做共享或生产吞吐优化。

按需 B 的原 17 项完整 canonical 状态与原 B 一致；End City 原门禁只比较非实体完整状态和实际输入，完整实体 hash 不标等价。该目标实际有三只潜影贝，两侧原始记录各三只，本页此前误写为六只；现有证据未改写。新增独立末地城门禁已严格比较完整实体，仅按批准且由独立原版证实的 UUID/水平朝向规则单独验收，其它字段与位置一致；canonical 仍只有 UUID 例外，不确定化原版 Rotation。

保留 Mineshaft 矿车和 306 个 block ticks、EndSpike 水晶、Monument 的 264 个 fluid ticks、village-edge 的 420 个后处理位置，以及真实结构 BE。自然生成案例的最终 pending NBT 数仍为零，人工构造测试不计作自然正例。

局部列复算使用既有 72 项地形与 18 项结构的独立物理原版证据：720 个候选中 699 列、231,552 个方块及四种高度图一致，21 列明确回退。数据是对保留证据的复算，不冒充重新创建 90 个原版世界。紧凑模块的较远 referenced start 导出已验证，但尚无对应的新 Artifact/Overlay 物理交接证明。

按需 B 的受限模块采样平均约 495 → 401 ms，但原 B 先执行，新 B 含读取校验和回退快照，且个别目标没有提速；它不是无偏生产 benchmark 或人工探索验收。新 A 的对象减少也不直接证明探索更快。完整 A 保持 PARTIAL；C 的[跨界贡献候选](../design/architecture-features.md)已包含自然目标 decoration loop，但不代表完整 C 动态物理接收或存档接入通过。

C 的临时外部反馈仅在一个原版 placed-feature 槽内有效；目标内结果保留，槽外读取重新观察纯 TERRAIN。区域辅助 RNG 与 tick 次序共享目标 loop，不逐树木槽重置。这个有限因果边界是实验候选，不等于完整 Vanilla 九 writer parity。C 只放行整项配置均通过审计的树木；未知树种、混合选择器或 provider 整项使用 B。当前自然完整流程的外部蜂巢、fluid ticks、后处理和目标 pending NBT 均为零；自然目标内的 BE、实体、两类 tick、后处理均有正例。蜂巢等更完整输出仍由单树内核另证，不混淆两者覆盖。End City 用独立有限门禁补齐，不混入原 21 项 UUID-only 严格 C 套件。

C 的接收实验只向接收者 B 基底的未保护空气投影：每宿主接受 270 个位置（含 14 个针叶树方块）、2 个蜂巢及 113 个 block ticks，另有 7 个接收者验证保护挖空位置。原始记录的 199 个 block ticks、243 个 fluid ticks、32 个后处理位置均严格对照；202 个无对应方块写入的边缘副作用单独拒绝。当前实际被接受的 fluid tick/后处理为零，不能声明这两项的自然接收正例。单元测试的后处理正例、构造的玩家修改和冲突不充当物理玩法证据。

实际派生种子的扩展暴露了两项边界。化石 `FossilFeature.place` 的 `getLevel → getServer → getStructureTemplateManager` 只取模板资源，实验 B/C 已精确放行该入口；未知调用继续拒绝，不修改生产分流。另一项是 master `123456789`、Overworld `(-14,-13)`、local seed `804143585224698994` 的海底废墟溺尸：原 B、C 完整地形控制及其同输入重复在增援概率和击退抗性属性上不同，方块无差异，装饰 RNG 轨迹相同。26.3 字节码显示这两项使用实体自身非世界种子随机源。原始 NBT 与失败快照保存于 C frontier 结果，没有修改实体 RNG 或 canonical UUID-only 规则；新的有限验收单独保存，不覆盖旧失败。

固定输入接收用同一份真实生成数据隔离上述生成重复性问题；没有删除随机字段或改用实体空列表。分别验证 pending 写盘重载、逐位置基底就绪、逆序与三线程重复投递、保护、删除再投递和另一 JVM 的重放。两个进程重放阶段的生成调用均为零、physical 状态不变、context 无残留；原始目标未被写入。当前自然数据中没有接收者再次外溢，最终 pending 为零；缺失基底阶段有 pending 正例，但不能称自然二级外溢已覆盖。被接受的 fluid tick、后处理与蜂巢仍为零，不扩大正例范围。

该溺尸另有普通原版物理路径证据，不再只依赖实验 B/C 的共同实现。独立原版没有建立 isolated context，也没有调用 A/B/C，状态调用为 529 次 STRUCTURE_STARTS、49 次 STRUCTURE_REFERENCES、49 次 BIOMES、25 次 TERRAIN 和 9 次 FEATURES；捕获前无 LIGHT/SPAWN/FULL。属性按名称辅助对照只出现上述两个数值差异，`follow_range/random_spawn_bonus` 在这三次重复中一致；其读取 region RNG，不是实体自己的无种子 RNG。使用者已批准有限例外，当前 probe 按[有限验收规则](../design/architecture-features.md#原版随机字段的有限验收)执行，不删除 attributes 或泛化随机字段。两个宿主分别记录 43/97 次比较，只有 4/5 次需例外（含各自核验的两次原版重复）；原始字段、严格哈希和其余数据均保留。

末地城的独立物理重复使用同级别路径，状态调用数相同；新增有限门禁在两个宿主记录 14/18 次比较，其中 8/10 次使用已证明的朝向例外（含原版重复），其余严格相同。潜影贝 `Rotation[1]`、数量、顺序、位置、生命、附着面与其它字段始终严格，非法类型和超出构造器范围的水平朝向拒绝。两个实体规则显式分开，末地城门禁不会顺便放行溺尸随机属性。

物理接收机制已有蜂巢入站正例，但仍没有 fluid tick 或后处理入站。tick 数是原始贡献记录，不是已执行次数；整批原版方块通知完成后再取实际调度器保存边界，保留原版去重和邻接通知产生的数据。后处理非空在 post-FULL 接收中明确拒绝。激活前的写盘/存档中断已有独立恢复证据，但不推广到已 FULL 的批次事务或电源故障。兼容的迟到贡献现可增量追加，要求替换旧方块或附属副作用的冲突仍只能等待，不能用先来先占冒充顺序独立。动态生产接收和真实玩家事件仍未验收；BE 内容比对只证明接收时保护已改变 payload，不是完整交互事件监听。

蜂巢专项发现并纠正了验证层次混用：原版 LevelChunk 保存 BE 时添加 `keepPacked=false`，ProtoChunk 已实例化 BE 的 payload 没有该封装标志。现在先严格比较完整 payload，再检查存储封装精确符合原版行为；没有扩大 BE/实体的 canonical 忽略列表，也没有修改蜂巢生成或生产接收。原始失败日志留在验证记录/回收站，新成功结果独立于旧无蜂巢套件。

## 三方案同输入比较

独立比较入口实际完成 12 个代表目标 × A/B/C × 三次轮换样本 × 两个无关宿主，共 216 次实验生成；每个宿主另外执行 12 次保留的九 writer reference。目标的完整 TERRAIN 输入、A 的 B 准备快照、同方案重复及跨宿主最终快照与 C 原始贡献均一致。每条实验路径恰好一个完整 FEATURES writer、不执行邻区完整 FEATURES；九 writer 仅在 reference 对照运行。后续光照与 physical 接收均未执行。两个宿主的已加载 Chunk、实体及两类 scheduler 计数不变，bindings 为零。

四逻辑 CPU、低优先级、串行会话；每个目标取三次中位数后，在目标和宿主间取平均。包括 context 建立、装饰前准备、精确回退和 FEATURES，排除快照与写盘：

| 方案 | 平均目标耗时 | 与九 writer 参考的差异方块总数 | 当前证据含义 |
| --- | --- | --- | --- |
| A | 1,423 ms | 2,362 | 11 个目标补回内容，但仅支持已审计矿脉/岩石置换和树木，仍非完整还原 |
| B | 325 ms | 12,779 | 严格目标基线，省去邻区装饰贡献 |
| C | 338 ms | 12,675 | 4 个自然目标有跨界贡献包，包含针叶林；接收未计时、未物理应用 |

这是模块取舍数据，不是 production chunks/s。两个宿主轮次的均值为 A 1,402/1,445 ms、B 320/331 ms、C 318/358 ms；这些小样本和跨轮波动不能当成稳定吞吐、宿主种子引起的性能差异或本次优化收益。A 的矿脉贡献求值约占本组 A 样本总耗时的七成，较 B 约为 4.4 倍成本；没有据此修改查询算法或进入 D2。减少完整邻区对象并未自动换来较低的总计算成本。

方块差异总数是同一 12 目标的求和，两宿主结果相同；它不是完整正确率，也不包含 C 尚未接收的树冠。代表白桦目标与参考的差异从 B 的 1,385 个降至 A 的 158 个，但 metadata 仍分别报告，未声称全量 parity。A 每项目标实际遇到的未支持 feature 为 2～50 项，邻区结构始终单独标为未重建，不把未支持项静默视为完成。

C 的自然出站来源为 mineshaft、birch-0、birch-1、taiga-0，共 289 条方块记录和 270 个原始 block ticks；其它附属出站能力在本组为零，不增加正例声称。taiga-0 的目标相对 B 改变 25 个叶片状态，同时保持与完整地形 C 控制等价；它不是恢复邻区 writer 的证据。目标内的矿车/末地水晶、试炼密室 BE、方块/流体 ticks 与村庄后处理正例均保留。完整地形调用观测计入贡献内部回退：11 个目标三方案均无完整邻区，birch-1 的 A/B/C 分别为 7/4/4 次；局部列、噪声批次和 biome-only 输入仍存在，计数不代表全部邻区工作消失。

比较结果只标 `PASS_COMPARISON_ONLY`。九 writer 对照是保留的 isolated V1，不冒充新建独立物理原版世界；没有以此绕过溺尸/Shulker 原生随机字段、C 物理接收、存档交接或人工视觉的未完成门槛。
