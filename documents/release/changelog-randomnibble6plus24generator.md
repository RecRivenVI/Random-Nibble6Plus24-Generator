# 更新日志

适用于 Minecraft Java 26.3 Fabric 与保留的 26.2 Fabric。

## [未发布]

### 新增

- 登记 26.3 NeoForge、26.1.2 NeoForge、1.21.1 NeoForge 与 1.20.1 Forge 移植目标；尚未完成生成和游戏验收，不声明可游玩，现有 Fabric 存档不变。

### 变更

- 为全新 B 开发地图接入按需同种子读取与真实物理生命周期，显式区分旧地图，保留原始随机行为；未开放正式创建入口。
- 26.3 增加显式的新地图单区块装饰试验规则：只运行目标区块装饰并丢弃越界生成写入；既有地图和默认九区块装饰规则不变。
- 新增独立的 26.3 Fabric 移植与验证入口并切换为参考版本，保留 26.2 实例、存档和历史 golden；冻结种子、FEATURES 顺序与 Mosaic profile 格式不变。
- 构建规范整体升级到 1.2.2，并对齐 Java 格式工具与 Markdown 检查器。
- 与游戏版本无关的生命周期和隔离值类型移入产品组件，发行包仍包含相同 Java 包中的类。
- 迁移目录、构建与实例配置，统一开发验证入口；世界生成、存档和网络语义不变。
- 编译用 Fabric Loader 升级为 0.19.5，保留最低要求 0.19.3。

### 修复

- 26.3 Fabric 与移植中的 NeoForge 在复用结构来源时核对原生群系查询缓存的入口，并恢复同样的查询出口；未知环境精确回退，避免相同坐标下复用不同查询上下文。已保存区块不重写，生成与存档合同不变。
- 移植中的 1.20.1 隐藏 B 世界在原生生成准备边界响应正常关闭，真实异常退出时也排空所属任务；真实生成错误和意外取消仍正常报错，不改变已保存区块或生成规则。
- 26.3 安装 TerraBlender 时，隔离生成和 SPAWN 备用群系查询独立初始化本地种子配置，避免借用宿主种子的群系区域；已保存区块和 B 切断合同不变。BOP 完整兼容仍受末地原生装饰排序不稳定限制。
- 26.3 B 开发地图在一次生成内复用已完成的生物群系调色板与只读查询准备，避免精确回退重复构建；无法证明的地形仍走原版完整回退，既有存档规则不变。
- 26.3 B 邻区密度改为按读取位置调用原版小批次并复用插值角点，避免一次局部读取计算整份密度；未证明输入保留精确回退，B 结果与既有存档规则不变。
- 26.3 B 开发地图先审计邻区局部查询能力，按需处理表面列并复用经证明的高度；未证明输入仍精确回退，生成结果和既有存档不变。
- 26.3 B 开发地图将完整地形证明采集移出日常生成交接，保留轻量计数与必要校验；生成结果和既有存档规则不变。
- 26.3 B 开发地图将共享结构保护缩到模板缓存和必要的静态生成状态，避免村庄、试炼密室的完整拼装互相阻塞；生成规则和既有存档不变。
- 26.3 B 开发地图在一次目标生成内复用原版结构来源求值，避免邻区局部查询重复构建；结构放置使用独占可变对象，生成结果、切断边界和既有地图保持。
- 26.3 区块完成时改为增量清理物理生成依赖，避免反复扫描所有活动计划；生成结果、存档规则与依赖状态要求不变。
- 26.3 运行期环境属性查询所需的物理生物群系邻区改为真实物化数据，避免未生成的 palette 被调度状态误认为已就绪。
