# B 邻区局部地形按需查询

调查日期：2026-10-15。局部查询减少了不必要的整列处理，同条件两次优化版测量吞吐提高约 8%～11%；完整密度批次仍保留，不能称邻区计算已消除或达到原版速度。

## 问题

日常 B 已关闭完整列证明，但邻区高度读取仍可能创建整列表面与洞穴状态。无法支持的荒地、冰山规则也会先建立密度批次，再生成一次完整精确地形作为回退。完成列的同一种高度会重复扫描。

## 方法

直接检查本地 Minecraft 26.3 的 `NoiseChunk`、`SamplerContext`、`InterpolatedFunction`、`Aquifer`、`MaterialRuleContext` 与 `MaterialSystem`。原版体积缓存与逐点采样可能采用不同浮点计算路径；本轮不以单点采样替代原版密度批次。

先取得实际 stored palette 并执行闭合能力审计，无法证明时不建立密度批次，直接走原有精确回退。支持批次仍保留原版完整体积；每列找到最高非空气和海床格后停止含水层扫描。最高 section、表面梯度与原版规则输入不变。

只问高度时，只有表面规则保持对应高度、洞穴掩码在该最高有效格及上方为空，才复用已经精确计算的噪声高度。海床还必须按当前实际高度图标签证明所有可达替换保持不透明性。未知输出、未证明洞穴影响和其它能力仍还原完整精确列或完整地形。需要方块列时才编译表面规则；完成列不可变，其高度按需记忆。所有复用均限于一个目标、一个种子和一个生成上下文，关闭后查询拒绝。

## 发现

先运行修改前版本，再运行修改后版本。两组各一个 fresh world、一个 Minecraft JVM、四逻辑 CPU、低优先级、8/8、master seed 123456789、中心 (125,-37) 和相同 60 秒 PLAYER ticket 轨迹。固定输出在被忽略的 `versions/26.3-fabric/build/research/b-local-terrain/before/` 与 `after/`。

| 同条件 60 秒 | 修改前 | 按需查询 |
| --- | --- | --- |
| canonical 完成 | 463 | 500 |
| canonical/s | 7.71 | 8.33 |
| FULL 完成 | 225 | 255 |
| 发送就绪 | 169 | 192 |
| 初始中心 ENTITY_TICKING 就绪代理 | 25.12 s | 19.41 s |
| 第 55 秒当前视野就绪 | 51.2% | 58.5% |
| 完成目标平均耗时 | 680 ms | 742 ms |
| 完成目标耗时中位数 | 427 ms | 495 ms |

| GC 暂停累计 | 1.91 s | 1.70 s |

最后补上荒地七种输出按当前实际海床标签核验的保护；无法证明时不能只凭规则类型认定海床不变。最终源码在相同条件重新测量：513 次 canonical、8.55/s、FULL 266、发送就绪 199，中心就绪代理 21.03 s、第 55 秒当前视野就绪 58.5%。平均目标耗时 683 ms，中位数 475 ms；GC 累计 1.77 s，分配量采样估计 44.64 GB。保护后的两个宿主完整 B 和 90 项局部列对照重新通过。

这里只有一次修改前与两次优化版测量，不能排除全部运行噪声。完成目标集合随前沿进度变化，并非同一组逐目标延迟实验；平均目标耗时没有下降，不包装成单区块全面提速。CPU 数值是嵌套 inclusive 样本，不能相加。分配量是采样估计；本轮没有证明分配量下降。CLI 没有玩家登录、客户端 packet 或画面，中心代理与发送就绪不是首次玩家进入或实际渲染时间。

原 B 实际读取对照的代表案例中，白桦完整局部列从 614 减到 147，海底神殿从 1,045 减到 279。其完整目标、读取值、随机轨迹与精确回退仍判等。测量记录累计 1,314,869 次严格高度快速回答和 1,122,367 次完成列高度复用；完整噪声与 material 批次仍分别有 3,761 和 3,524 次。这些是测量记录累计值，不是每目标或严格裁剪到 workload 窗口的次数。

两个独立宿主各 18 项完整 B 读取与目标对照、各 19 项实际交接通过，保留随机序列、stored biome、结构、Artifact 原始实体和零证明热路径。七类结构、邻区 start 与地形适配的 18 项 fresh 原版装饰前对照通过。局部查询另在两个宿主各重算 72 项矩阵加 18 项结构的既有独立原版输入：每宿主 699 条完整列、231,552 个方块格、四种高度及密度 raw bits 一致，21 条未证明列实际精确回退也一致；4,052 次高度快速回答与 4,053 次完成列复用有正例。这不是新生成了 90 个原版控制世界。

白桦、矿脉和 C 完整目标 FEATURES 的两宿主回归通过；它们只证明各自既有支持范围，没有扩展 A/C。B 保存重启后 Artifact/SPAWN 生成均为零、修改保留；32 次同目标请求只生成一次目标 Artifact，in-flight 为零。旧 Ordering 1/2 保存重载与普通 Vanilla 前沿通过。测量中身份文件验证只有生命周期的两次，SPAWN 携带快照快速路径继续命中。

## 结论

减少高度查询与失败局部查询的重复工作可以保持 B 结果，不改变旧地图分流、种子、装饰切断规则或 Artifact。首轮端到端收益有限，主要剩余成本仍是完整密度批次及生物群系、表面规则；更细粒度采样还没有严格等价证明。本轮不以近似值进一步裁剪，不自动进入其它优化，人工不限 CPU 探索效果另由使用者验收。
