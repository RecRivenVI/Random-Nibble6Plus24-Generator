# Mosaic 世界

适用于 Minecraft Java 26.3 Fabric 与保留的 26.2 Fabric。26.3 已通过进入、探索、保存退出与重进验收；升级游玩前仍应备份原世界。不同区块使用不同派生种子，地形与结构在边界直接截断，尚未开放正式创建世界入口。

## 游玩与命令

已有单人存档可飞行探索新区。`/seed` 显示世界种子和当前位置区块种子；`/locate structure` 仅搜索已生成、已记录的区域，不探索未生成区域。

光照、流体、实体移动和运行期交互使用真实物理邻区。生成速度仍低于原版，中高视距持续飞行可能等待新区补齐。

## 限制

WorldPreset、未生成区域全局结构搜索与 Preview 均未开放。D1 候选裁剪的历史性能验收为 PARTIAL，不代表已达到原版速度。

26.3 为保证运行期生物群系查询正确，会准备更多冷区邻区数据，探索速度仍需单独评估；本次升级通过不代表生成性能已经达到原版。

后续版本将持续跟进 Minecraft 最新正式版与最新 Fabric Loader，只有 Loader 可以采用测试版。本页仅适用于开头注明的版本；验证新版请使用独立世界或备份，不直接覆盖已有游玩存档。
