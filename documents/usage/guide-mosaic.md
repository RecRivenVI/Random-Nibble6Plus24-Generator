# Mosaic 世界

适用于 Minecraft Java 26.3 Fabric 与保留的 26.2 Fabric。26.3 已通过进入、探索、保存退出与重进验收；升级游玩前仍应备份原世界。不同区块使用不同派生种子，地形与结构在边界直接截断，尚未开放正式创建世界入口。

26.3 NeoForge、26.1.2 NeoForge、1.21.1 NeoForge 与 1.20.1 Forge 已进入移植工作，尚未完成生成和游戏验收，暂不可用于游玩或打开正式 Mosaic 存档。它们的登记不改变现有 Fabric 世界。

## 游玩与命令

已有单人存档可飞行探索新区。`/seed` 显示世界种子和当前位置区块种子；`/locate structure` 仅搜索已生成、已记录的区域，不探索未生成区域。

光照、流体、实体移动和运行期交互使用真实物理邻区。生成速度仍低于原版，中高视距持续飞行可能等待新区补齐。

新准备的 `Mosaic B Milestone Fresh` 是独立的按需 B 实验地图，默认创造模式、命令可用。装饰严格切断，未生成区域继续使用同一规则；它不会修改旧世界。新地图的进入、持续探索和保存重进仍待人工验收，暂不承诺性能提升。

## 限制

26.3 的单区块装饰测试地图只执行当前区块的装饰，丢弃越界生成写入。树冠、矿脉、植被和结构可能截断，装饰密度也可能变化；邻区地形读取仍来自同种子生成环境。这不是原版装饰结果的完整复刻，也不保证九倍提速。旧地图继续使用原来的九区块装饰规则，不自动转换。

B 的地牢还可能受到切断的间接影响：边界外未被挖空的地形会改变箱子位置，箱子可能占据刷怪笼中心。原版保护规则不允许刷怪笼覆盖箱子，此时会记录刷怪笼告警，实际保留下来的是正常箱子，并非方块实体丢失；这些地牢可能没有刷怪笼。

Mosaic 创建世界入口尚未公开，结构搜索只覆盖已生成区域。现有性能验收不代表已达到原版速度。

26.3 的结构结果仅在查询上下文一致、环境已验证时安全复用；无法确认时使用精确原版回退，不以近似数据提速，也不重写已生成区块。

Biomes O' Plenty 兼容仍处于验证阶段，不自动安装到已有世界。TerraBlender 的本地种子隔离已修正，但当前版本的末地装饰存在原生跨进程不稳定结果，尚不能承诺完整兼容或相同输入得到唯一装饰结果；请先使用独立测试世界。

26.3 为保证运行期生物群系查询正确，会准备更多冷区邻区数据，探索速度仍需单独评估；本次升级通过不代表生成性能已经达到原版。

本页仅适用于开头注明的版本；验证其它版本请使用独立世界或备份，不直接覆盖已有游玩存档。
