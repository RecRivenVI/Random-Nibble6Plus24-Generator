# Mosaic 世界

适用于 Minecraft Java 26.3 Fabric／NeoForge 与保留的 26.2 Fabric。26.3 的有限进入、探索、保存退出与重进场景已验证；升级游玩前仍应备份原世界。不同区块使用不同派生种子，地形与结构在边界直接截断，尚未开放正式创建世界入口。

首版游玩支持仅包括两个 26.3 端。1.20.1、1.21.1、26.1.2 暂不提供游玩支持，保留源码与构建；26.1.2 的冷末地切换可能触发服务端看门狗，另两端完整加载前沿仍有阻断。不建议用这些版本建立正式存档。

## 游玩与命令

已有单人存档可飞行探索新区。`/seed` 显示世界种子和当前位置区块种子。26.3 的 Mosaic `/locate structure`、`/locate biome` 与 `/locate poi` 均提示暂不支持；已生成区域也不开放定位。

26.3 Mosaic 世界中的末影之眼不会被扔出，制图师不提供探险地图，结构地图战利品保留为没有目的地的空地图，喂食海豚后不会开始寻宝。这些行为按原版“找不到”的分支处理，不影响普通原版世界。结构本身、结构判断和保存数据仍保留；26.2 的既有定位行为不在本轮改变。

光照、流体、实体移动和运行期交互使用真实物理邻区。性能 PARTIAL 已作为当前版本限制接受，不再研究装饰优化：四逻辑 CPU、相同主世界新区探索负载下，Fabric 的发送就绪吞吐约为原版的 78%／40%／23%（视距 8／12／16），NeoForge 约为 75%／37%／20%。8 视距冷区的中位就绪等待约为原版四至五倍；更高视距有超过一分钟观察窗仍未完成的请求。不同区块的独立种子、精确邻区读取及物理邻区就绪是主要额外代价，不承诺原版速度。

项目准备的独立 B 测试地图允许创造模式与命令。装饰严格切断，未生成区域继续使用同一规则；它不会修改旧世界。正式创建世界入口尚未公开。

## 限制

26.3 的单区块装饰测试地图只执行当前区块的装饰，丢弃越界生成写入。树冠、矿脉、植被和结构可能截断，装饰密度也可能变化；邻区地形读取仍来自同种子生成环境。这不是原版装饰结果的完整复刻，也不保证九倍提速。旧地图继续使用原来的九区块装饰规则，不自动转换。

B 的地牢还可能受到切断的间接影响：边界外未被挖空的地形会改变箱子位置，箱子可能占据刷怪笼中心。原版保护规则不允许刷怪笼覆盖箱子，此时会记录刷怪笼告警，实际保留下来的是正常箱子，并非方块实体丢失；这些地牢可能没有刷怪笼。

Mosaic 创建世界入口尚未公开，26.3 的定位功能暂时关闭。现有性能验收不代表已达到原版速度。

26.3 的结构结果仅在查询上下文一致、环境已验证时安全复用；无法确认时使用精确原版回退，不以近似数据提速，也不重写已生成区块。

Biomes O' Plenty 兼容仍处于验证阶段，不自动安装到已有世界。TerraBlender 的本地种子隔离已修正，但当前版本的末地装饰存在原生跨进程不稳定结果，尚不能承诺完整兼容或相同输入得到唯一装饰结果；请先使用独立测试世界。

26.3 为保证运行期生物群系查询正确，会准备更多冷区邻区数据，探索速度仍需单独评估；本次升级通过不代表生成性能已经达到原版。

本页仅适用于开头注明的版本；验证其它版本请使用独立世界或备份，不直接覆盖已有游玩存档。
